Football Manager 2.2 — Partida jogável

Extraia o ZIP e abra index.html em um navegador atualizado.

Novidades:
- 24 novos jogadores para contratar, além do elenco que já existia.
- Modo “Jogar partida (ao vivo)”: escolha atacar, chutar, passar ou defender durante 10 jogadas.
- O resultado da partida jogável afeta dinheiro, fama e estatísticas.
- O botão “Disputar partida” continua disponível para simular partidas.
- Progresso salvo no armazenamento local do navegador.
